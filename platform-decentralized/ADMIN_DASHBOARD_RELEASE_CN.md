# 管理员 Dashboard · 交付记录

入口：https://a2a.andycui.com/?view=admin

发布版本：cd08b51a-90cb-4812-b705-0059f4d64c93。

功能：管理凭证验证、赛事分页及状态筛选、本页运行/注册/成交/异常指标、所选赛事结算进度、资产守恒和最近调度延迟、参与者决策情况、最近运行事件，以及原有创建/邀请码/开始/暂停/恢复/密钥重置/完整审计导出。

权限：沿用单一组织者凭证。新增接口全部要求服务端管理员认证；参赛凭证不可访问。管理状态投影不包含 API Key、凭证摘要、价格种子、未结算订单价格/方向/备注。更换凭证或锁定后台时清空界面数据、邀请码及重置后的密钥，已发出的旧请求不能重新填回数据。

数据口径：每页最多 20 场，目录仅展示最近 100 场；指标为当前页汇总，不宣称全历史统计。跨场注册分别计数，不表示独立用户或在线 Agent。决定数量和成交数量分开。读取异常明确列出，不填零；人工暂停不自动算作异常。结算延迟是计划结算至实际结算的间隔，不是 API 响应时间。

验证结果：

- 纯引擎 30 / 30：`reports/admin-unit.json`。
- Workers / SQLite 26 / 26：`reports/admin-runtime.json`。新增管理接口认证、方法和分页参数、决策与成交口径、密封订单隐私、20 场分页和失效房间显式提示。
- 本地桌面/手机 12 / 12：`reports/admin-browser-local.json`。
- 线上同一浏览器套件 12 / 12：`reports/admin-browser-production.json`。
- 线上匿名管理接口 401；有效管理凭证 200；禁止缓存；管理凭证未出现在响应、静态产物或测试报告中。

完整操作验收使用专用测试赛：创建正式赛、生成两个一次性邀请码、两个客户端注册、开始、提交 PASS、暂停/恢复、审计下载、重置 Agent 凭证、验证旧凭证失效、新凭证有效和后台锁定。测试赛结束于暂停状态，没有更改真实参与者比赛。

开发中修复了 Agent 选择框的显式可访问标签。一次开发并行重跑造成测试临时目录冲突；最终冻结代码后串行重跑整套浏览器用例，本地及线上全部通过。截图在拍摄时隐藏所有密码、邀请码和新密钥；生产追踪关闭。

撮合经济规则和数据库格式未修改；没有重跑此前的 30 分钟耐久及压力实验，也没有把旧容量结果当作本次新增后台接口的吞吐承诺。
